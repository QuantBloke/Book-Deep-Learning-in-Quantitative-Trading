### Gotchas worth flagging

- **`pyproject.toml` type-check scope.** `[tool.pyright].include = ["src"]` but there is no `src/` directory — pyright currently checks nothing. Widening to `["Utilis", "Chapter*"]` would make `uv run pyright` useful.
- **Stale `README.md`.** Describes a conda workflow; `pyproject.toml` + `uv.lock` are the real source of truth.
- **Notebooks are CWD-sensitive.** The `sys.path` shim and the `pd.read_csv('../Data/...')` / `EarlyStopping(savepath='model/...')` patterns assume you run each notebook from its own chapter directory. Papermill/nbconvert invocations must `cd` first.
- **`Utilis` spelling.** Typo or not, it is the canonical package name. Do not rename.
- **Checkpoints are committed.** Re-running any training notebook dirties `Chapter*/model/*` in git. This is expected — but treat it as intentional churn in diffs, not as a bug.
